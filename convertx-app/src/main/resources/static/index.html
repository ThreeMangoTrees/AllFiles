ConvertX

Convert, compress, and merge PDFs.

Turn common files into PDF, compress an existing PDF with 25%, 50%, or 75% compression profiles, or merge two or more PDFs into one document.

Upload two or more supported files. Non-PDF files are converted first, then everything is merged in the same order. Choose 100% to skip compression.

Convert

Any supported file to PDF

Accepts docx, xlsx, pptx, jpg, jpeg, tiff, gif, bmp, txt, rtf, html, htm, and heic.

Rotate

Rotate PDFs, images, and text files

Upload a PDF, image, or text file and rotate it anti-clockwise by 90, 180, or 270 degrees. Images stay in the same format, while text files are converted to PDF first.

Compress

Reduce a PDF

Upload one PDF and choose a compression profile. Higher compression usually means lower fidelity.

Compression uses Ghostscript profiles. Output size is approximate, not guaranteed exact.

Merge

Combine multiple PDFs

Upload two or more PDFs. Files are merged in the order you select them.
